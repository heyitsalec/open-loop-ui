# Starter Issues

Use these as the first public issues after the repo is published.

## Add a Next.js route handler example

Labels: `good first issue`, `example`, `nextjs`

Create an `examples/next-route-handler` flow that shows a browser-safe provider calling a route handler, with the route handler logging or forwarding the Open Loop payload.

## Add a tiny demo video

Labels: `good first issue`, `docs`, `visuals`

Record a 20-30 second clip of pill -> target -> submit -> JSON handoff. Save it as `docs/assets/open-loop-demo.webm` or a small GIF and embed it near the top of the README.

## Add theme presets

Labels: `good first issue`, `theming`

Add documented CSS variable presets for quiet SaaS, high-contrast, and playful demo themes.

## Add adapter recipes

Labels: `good first issue`, `adapter`

Document tiny adapter examples for Linear, GitHub Issues, local file logging, and CLI handoff without adding provider-specific code to the package.

## Improve focus trap coverage

Labels: `good first issue`, `accessibility`, `tests`

Add focused tests for Tab and Shift+Tab behavior in the panel, including disabled submit states.
